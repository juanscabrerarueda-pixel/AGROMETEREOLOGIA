## Reporte de vulnerabilidades

- Por favor no abras issues publicos con detalles sensibles.
- Usa "Report a vulnerability" en GitHub Security Advisories para compartir el hallazgo de forma privada.
- Si no puedes usar Advisories, abre un issue sin detalles tecnicos pidiendo un canal de contacto o envia correo a nuestro contacto de soporte (segun README) con un resumen.

## Versiones soportadas

Este proyecto no tiene releases; el branch `main` es la rama soportada. Problemas en versiones antiguas pueden no ser atendidos.
