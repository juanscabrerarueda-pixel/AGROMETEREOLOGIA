Tendencia de Lluvias

Panel agrometeorológico interactivo que resume precipitaciones diarias e intensidad, pronósticos a 14 días y mapas horarios. Esta es la página índice del repositorio y contiene toda la información necesaria para ejecutar y desplegar la app moderna (apps/web).

Arquitectura del proyecto

  • apps/web: Aplicación React + Vite (la interfaz oscura de las capturas).
  • apps/api: API local usada durante el desarrollo (pnpm --filter api dev).
  • packages/*: Paquetes internos (cálculos meteorológicos, caches, insights, etc.).
  • docs/: Versión compilada para GitHub Pages (incluye .nojekyll).
  • start-demo.cmd: Script que levanta API + web preview y abre http://localhost:4173/.

Cómo trabajar en local

  1. Instala dependencias una vez: pnpm install.
  2. Ejecuta start-demo.cmd (o pnpm --filter api dev + pnpm --filter web preview). Al terminar se abre http://localhost:4173/.
  3. Para generar la build: pnpm --filter web build. El resultado queda en apps/web/dist.

Deploy en GitHub Pages

La carpeta docs/ contiene la última build lista para producción. Siempre que quieras publicar una nueva versión:

  1. Corre pnpm --filter web build.
  2. Reemplaza docs/ con el contenido de apps/web/dist.
  3. Asegúrate de que docs/.nojekyll exista (evita que GitHub procese el sitio con Jekyll).
  4. Haz git add docs, git commit y git push origin main.
  5. En Settings → Pages usa Branch: main /docs. El build se actualizará en cuanto GitHub procese el nuevo commit.
